# Weapon Duel

A simple local two-player Python game made with Pygame.

## Setup

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python weapon_duel.py
```

## Controls

| Player | Move | Shoot |
| --- | --- | --- |
| Blue | W A S D | V |
| Red | Arrow keys | Space |

Movement also sets each player's aim direction. A player wins after landing five shots. Press `R` after a win to start again.
