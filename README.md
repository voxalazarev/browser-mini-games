# Games

All games use the shared root virtual environment.

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Run a game with one of these commands:

```bash
python weapon_duel.py
python music_battle.py
python co_op_obby.py
python song_battle_arena.py
python weapon_roll_battle.py
```

`co_op_obby_progress.json` stores the Obby's unlocked-level progress.

## Browser games (GitHub Pages)

The folders `tag`, `tag_3d_backup` (Tag 3D), `obby`, `obby2`, `fighter`, `bike`, `motox`, `tennis`, `pingpong`, `golf` and `catch` are plain HTML/JS games. Open `index.html` for a menu of all of them, or play online via GitHub Pages.
